# Tableaux de bord Kibana

Déposez ici les exports `.ndjson` de vos tableaux de bord.

- **Exporter** : Kibana → Stack Management → Saved Objects → cocher le tableau de bord → Export
  (laisser « Include related objects » activé).
- **Importer** : même écran → Import → choisir le fichier `.ndjson`.
